This assignment covers the following programming questions:

1. Displaying "Hello World" and using control characters (`\n`, `\t`, `\a`, `\r`)
2. Celsius to Fahrenheit temperature conversion
3. Demonstrating `for`, `while`, and `do-while` loop variations
4. Creating a `Student` structure with data members and member functions
5. Differentiating `private` vs `public` access; implementing Question 4 using a class
6. Calling private member functions from within public member functions
7. Implementing a `Complex` class with private properties and public methods (`set()`, `display()`, `sum()`)
8. Demonstrating the use of `namespace` to avoid naming conflicts
